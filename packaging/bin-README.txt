Optional portable runtime directory.

Place your installed mpv.exe, ffmpeg.exe and ffprobe.exe here, together with all
DLLs required by their providers. For YouTube add yt-dlp.exe and install a
supported JavaScript runtime such as Deno on PATH.

Or install those programs on PATH and leave this directory empty.

Official starting points:
https://mpv.io/installation/
https://ffmpeg.org/download.html#build-windows
https://github.com/yt-dlp/yt-dlp#installation
https://deno.com/

This release deliberately does not redistribute those separate media tools.
